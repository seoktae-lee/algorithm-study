# Week 1 - 0320 자료구조/알고리즘

## 오늘 푼 문제
- 백준 10818 최소최대 (배열)

## 풀이 방법
### 방법 1 - 직접 구현
- 첫 번째 값으로 max, min 초기화
- for문으로 두 번째 값부터 순회
- 비교해서 더 크면 max 갱신, 더 작으면 min 갱신
- elif 대신 if 써야 두 조건 모두 검사 가능

### 방법 2 - 내장함수
- min(), max() 한 줄로 해결
- 코딩테스트에서 빠르게 풀 때 유리할 듯

## 새로 배운 것
- map(int, input().split()) : 공백으로 구분된 입력을 정수 리스트로 변환
- list 슬라이싱 nums[1:] : 두 번째 원소부터 끝까지
- elif vs if 차이 : elif는 앞 조건이 참이면 뒤 조건 검사 안 함

## 시간복잡도
- 방법 1: O(n) - 리스트 한 번 순회
- 방법 2: O(n) - 내장함수도 내부적으로 순회
