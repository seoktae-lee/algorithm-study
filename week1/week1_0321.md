## 오늘 푼 문제
- 프로그래머스 lv.1 : 같은 숫자는 싫어 (스택/큐)

---

## 문제 설명
배열 arr에서 연속으로 나타나는 같은 숫자는 하나만 남기고
전부 제거한 뒤 남은 수들을 return

예시)
- [1, 1, 3, 3, 0, 1, 1] → [1, 3, 0, 1]
- [4, 4, 4, 3, 3]       → [4, 3]

---

## 핵심 개념: 스택 (Stack)

### 스택이란?
- LIFO (Last In First Out) — 마지막에 넣은 것이 먼저 나옴
- Python에서는 list로 구현
- append() : 맨 뒤에 추가
- pop()     : 맨 뒤에서 꺼내기
- stack[-1] : 맨 위 값 확인 (꺼내지 않고 보기만)

### 스택 동작 예시
stack = []
stack.append(1)  → [1]
stack.append(3)  → [1, 3]
stack.append(0)  → [1, 3, 0]
stack[-1]        → 0  (맨 위 값 확인)
stack.pop()      → [1, 3]  (0이 빠져나옴)

---

## 풀이 방법

### 방법 1 - 스택 활용 (기본 풀이)
def solution(arr):
    stack = []
    for num in arr:
        if not stack or stack[-1] != num:
            stack.append(num)
    return stack

### 코드 한 줄씩 설명
1. stack = []
   → 빈 스택 생성

2. for num in arr:
   → arr을 처음부터 끝까지 하나씩 순회
   → 각 숫자를 num에 담음

3. if not stack or stack[-1] != num:
   → 조건 1: not stack
     - stack이 비어있으면 True
     - 비어있을 때 stack[-1] 하면 오류나서 이 조건 필수
   → 조건 2: stack[-1] != num
     - 스택 맨 위 숫자랑 지금 num이 다르면 True
   → or : 둘 중 하나만 True여도 실행

4. stack.append(num)
   → 조건이 True일 때만 스택에 추가

5. return stack
   → 완성된 스택 반환

### 흐름 직접 추적 (arr = [1, 1, 3, 3, 0])
num=1 → stack 비어있음(True)       → append → [1]
num=1 → stack[-1]=1 == 1 (False)   → 건너뜀 → [1]
num=3 → stack[-1]=1 != 3 (True)    → append → [1, 3]
num=3 → stack[-1]=3 == 3 (False)   → 건너뜀 → [1, 3]
num=0 → stack[-1]=3 != 0 (True)    → append → [1, 3, 0]
결과: [1, 3, 0] ✅

---

### 방법 2 - deque 활용 (성능 최적화)
from collections import deque

def solution(arr):
    stack = deque()
    for num in arr:
        if not stack or stack[-1] != num:
            stack.append(num)
    return list(stack)

# deque vs list 차이점
# - list  : append/pop → O(1) / 앞에서 삽입삭제 → O(n)
# - deque : 앞뒤 모두 O(1) → 큰 데이터에서 더 빠름
# - 이 문제는 배열 크기가 최대 1,000,000 → deque가 안전

---

### 방법 3 - 한 줄 풀이 (파이썬 고급)
def solution(arr):
    return [v for i, v in enumerate(arr) if i == 0 or arr[i-1] != v]

# enumerate : 인덱스랑 값을 동시에 꺼냄
# i == 0    : 첫 번째 원소는 무조건 포함
# arr[i-1] != v : 이전 값이랑 다를 때만 포함
# 리스트 컴프리헨션으로 한 줄에 해결

---

## 새로 배운 것
- not stack : 리스트가 비어있는지 확인하는 Pythonic한 방법
- stack[-1] : 리스트 맨 뒤 원소 접근 (음수 인덱스)
- deque     : 양방향 큐, 큰 데이터에서 list보다 빠름
- enumerate : 인덱스 + 값 동시 접근
- or 연산   : 첫 번째 조건이 True면 두 번째는 검사 안 함 (단락평가)

## 시간복잡도
- 방법 1, 2, 3 모두 O(n) — arr을 한 번만 순회

## 느낀 점
- 스택을 처음 써봤는데 "맨 위 값이랑 비교" 패턴이 핵심
- not stack 조건을 빠뜨리면 빈 리스트에서 오류 발생
- 같은 문제도 list/deque/컴프리헨션 등 다양한 방법으로 풀 수 있음
- deque는 데이터가 클 때 성능 차이가 남
