# L01. 타입 · 연산 · 형변환 · 오버플로

> ⏱ 25분 · 🎯 프로그래머스 `solution` 구조를 이해하고, **int 오버플로·정수 나눗셈**에서 틀리지 않기
> 🔗 cote 연결 문제: x만큼 간격이 있는 n개의 숫자(long), 최대공약수와 최소공배수

## 1. 프로그래머스 코드의 생김새

```java
class Solution {
    public long[] solution(int x, int n) {   // 반환 타입·매개변수는 문제가 정해 줌
        long[] answer = new long[n];
        // ...
        return answer;
    }
}
```

- `main`이 없어요. 채점기가 `new Solution().solution(...)`을 대신 호출합니다.
- **반환 타입을 꼭 보세요.** `long`/`long[]`이면 "int로는 넘친다"는 출제자의 힌트예요.

## 2. 기본 타입

| 타입 | 크기 | 범위 | 언제 |
|---|---|---|---|
| `int` | 4B | 약 ±21억 (2,147,483,647) | 기본 |
| `long` | 8B | 약 ±922경 | 곱셈·누적합·10^9 넘을 때 |
| `double` | 8B | 실수 (오차 있음) | 평균·비율 |
| `boolean` | - | true/false | 방문 체크 |
| `char` | 2B | 문자 = 숫자 | L04에서 |

```java
int big = Integer.MAX_VALUE;   // 2147483647
System.out.println(big + 1);   // -2147483648  ← 에러 없이 조용히 음수로 넘어감(오버플로)
long ok = 3_000_000_000L;      // long 리터럴은 L 접미사, _로 자리 구분 가능
```

## 3. 정수 연산의 함정

```java
7 / 2        // 3     정수끼리 나누면 소수점 버림
7 / 2.0      // 3.5   한쪽이 double이면 실수 나눗셈
-7 / 2       // -3    0 쪽으로 버림 (파이썬은 -4!)
-7 % 3       // -1    나머지 부호는 왼쪽 피연산자를 따름 (파이썬은 2)
Math.floorMod(-7, 3) // 2  음수에서도 0~m-1이 필요할 때

int a = 100_000, b = 100_000;
long wrong = a * b;          // 1410065408  ← int끼리 곱해서 이미 넘친 뒤 long에 담김
long right = (long) a * b;   // 10000000000 ← 곱하기 "전에" 한쪽을 long으로
```

## 4. 형변환 (casting)

```java
(int) 3.99        // 3   소수점 버림 (반올림 아님)
Math.round(3.5)   // 4   반올림 → long 반환
(int) Math.ceil(7 / 2.0)  // 4  올림
(a + b - 1) / b   // 양수 a, b의 올림 나눗셈 (실수 안 쓰고)
(double) sum / n  // 평균: 나누기 전에 double로
```

## 5. Math 자주 쓰는 것

`Math.max(a,b)`, `Math.min`, `Math.abs`, `Math.sqrt(x)`(double 반환), `Math.pow(a,b)`(**double 반환** → 정수 거듭제곱은 반복문 권장)

## 🐍 파이썬이랑 다른 점

- 파이썬 int는 무한정 커지지만 자바 int는 21억에서 **조용히** 넘칩니다. 에러도 안 나요.
- 파이썬 `//`는 음수에서 내림, 자바 `/`는 0 쪽으로 버림.
- 자바는 변수 타입을 선언하고 바꿀 수 없어요. `var x = 1;`도 되지만 타입은 int로 고정.

## ⚠️ 함정

1. `int * int`의 결과는 int — `long`에 담아도 이미 넘친 뒤
2. `sum / n`으로 평균 → 정수 나눗셈
3. 누적합·곱·거리 합이 10^9을 넘을 수 있으면 처음부터 `long`

## 📌 핵심 요약 (치트시트)

```java
long r = (long) a * b;            // 곱하기 전에 long
double avg = (double) sum / n;    // 나누기 전에 double
int ceil = (a + b - 1) / b;       // 양수 올림 나눗셈
int mod = Math.floorMod(x, m);    // 음수도 0~m-1
Integer.MAX_VALUE // 2147483647 ≈ 2.1×10^9 · long ≈ 9.2×10^18
```

## 🧩 연습문제 힌트

- q1: 배열 타입이 `long[]`. `answer[i] = (long) x * (i + 1);`
- q2: 곱하기 전에 캐스팅. `(long) a * b`
- q3: `(a + b - 1) / b`
- q4: 합은 int로 구해도 되지만 나눌 때 `(double) sum / arr.length`
- q5: `n % 10`으로 마지막 자리, `n /= 10`으로 지우기. `while (n > 0)`

## 🃏 복습 카드

- Q: `int`의 최댓값은 대략 얼마이고, 넘으면 어떻게 되나?
  A: 약 21억(2,147,483,647). 넘으면 에러 없이 음수로 돌아간다(오버플로) → 10^9 넘을 수 있으면 long
- Q: `int a = 100000, b = 100000; long c = a * b;` 의 문제점과 고친 코드는?
  A: int끼리 곱해서 넘친 뒤 long에 담김. `long c = (long) a * b;`
- Q: 자바에서 `7 / 2`, `-7 / 2`, `-7 % 3`의 결과는?
  A: 3, -3, -1 (0 쪽으로 버림, 나머지 부호는 왼쪽을 따름)
- Q: 양의 정수 a를 b로 나눈 몫을 올림하는 정수 연산식은?
  A: `(a + b - 1) / b`
- Q: `Math.pow(2, 10)`의 반환 타입과, 정수 거듭제곱에서 주의할 점은?
  A: double(1024.0). 큰 수는 정밀도가 깨지니 정수 거듭제곱은 반복문(또는 빠른 거듭제곱)으로
