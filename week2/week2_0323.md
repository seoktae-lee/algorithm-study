# [Week 2] 자료구조: 연결 리스트 (Linked List)

## 1. 연결 리스트의 정의
연결 리스트는 각 노드가 **데이터**와 **다음 노드를 가리키는 주소(포인터)**를 담고 있는 선형 자료구조입니다. 배열과 달리 메모리에 연속적으로 배치되지 않고, 포인터를 통해 논리적으로 연결됩니다.


## 2. 주요 특징 및 배열과의 비교
| 특징 | 배열 (Array) | 연결 리스트 (Linked List) |
| :--- | :--- | :--- |
| **메모리 할당** | 정적 (컴파일 타임) | 동적 (런타임) |
| **접근 속도** | $O(1)$ (인덱스 사용) | $O(n)$ (순차 탐색) |
| **삽입/삭제** | $O(n)$ (데이터 이동 필요) | $O(1)$ (포인터 변경만 필요) |

## 3. 연결 리스트의 종류
### ① 단방향 연결 리스트 (Singly Linked List)
- 각 노드가 다음 노드의 주소만 가집니다.
### ② 양방향 연결 리스트 (Doubly Linked List)
- 각 노드가 이전 노드와 다음 노드의 주소를 모두 가집니다. 양방향 탐색이 가능합니다.
### ③ 원형 연결 리스트 (Circular Linked List)
- 마지막 노드가 첫 번째 노드를 가리켜 고리 형태를 이룹니다.

## 4. 장단점 요약
- **장점**: 데이터 삽입과 삭제가 빈번한 경우 유리하며, 메모리 크기를 동적으로 조절할 수 있습니다.
- **단점**: 특정 위치의 데이터를 찾으려면 처음부터 훑어야 하므로 검색이 느리고, 포인터를 저장하기 위한 추가 메모리 공간이 필요합니다.
